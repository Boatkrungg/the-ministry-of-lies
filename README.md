# The Ministry of Lies

An English-only, luxury-parody website for generating fictional complaint documents. It is a first-year university project made with HTML, CSS, and vanilla JavaScript only.

## Open locally

1. Open this project folder.
2. Double-click `index.html` to open it in a browser.
3. Or use the Live Server extension in VS Code and select **Go Live**.

No framework, database, backend, or API is required.

## Files

- `index.html` contains the content and page structure.
- `style.css` creates the responsive luxury-comedy design.
- `script.js` handles form input, random receipts, stamps, statuses, sharing text, SVG download, and printing.

## Customise the jokes

At the top of `script.js`, edit `documentTypes`, `stamps`, `statuses`, and `endings` to add your own categories and jokes.

This is a satirical entertainment project, clearly labelled as not being a government agency. It uses no government seals or official symbols.
